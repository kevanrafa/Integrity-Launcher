# How To Add Account in Integrity Launcher
Cara Menambahkan Akun di Integrity Launcher itu simple
Kalian Tinggal ke Account Manager yang berada di paling kiri bawah atau nanti bakal pop up sendiri pada saat mencoba untuk memulai instances

![enter image description here](https://cdn.discordapp.com/attachments/879559618899107840/1548195716562821140/image.png?ex=6aa62d1e&is=6aa4db9e&hm=fcd22b2423613cf6c0ac74e4d11b7f0d6b7beff6eb4152fa0877b9251ce849b3&)
Kalian Bisa Memilih Untuk menggunakan Microsoft Account atau Offline Account
